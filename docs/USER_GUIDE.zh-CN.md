# 拍间 Tempo

为日常练琴制作的离线 Mac 节拍器与简易鼓机。界面和音频引擎独立编写，采用本地字体与矢量图形，无需账号或网络。

## 使用

从项目根目录运行 `npm ci`、`npm start`，或打开构建后的 `dist/mac-arm64/拍间 Tempo.app`。

- **速度：**30–240 BPM。点击数字输入，拖动刻度环，或用加减按钮微调。
- **模式：**在左上角切换「节拍器 / 鼓机」，共用速度、拍击定速、播放暂停、音量与练习设置。
- **拍号：**自由拍、1/4、2/4、3/4、4/4、5/4、6/8、7/8。6/8 和 7/8 以八分音符为一拍，界面会显示对应单位。
- **重音：**点击每一拍，按重音 → 轻音 → 静音循环。静音会同时关闭该拍的分拍声。
- **分拍：**每拍 1、2、3 或 4 声。播放中修改拍号或分拍，在下一小节生效。
- **拍击定速：**连续点击「拍击定速」或敲 T，按最近几次拍击计算平均速度。
- **音色：**木块、电子、鼓边、轻敲。静音保留原有音量。
- **练习：**设置每隔几小节增加多少 BPM、目标速度和定时结束。定时与本次计时仅累计播放时间，暂停后可以继续。
- **常用节奏：**3 个速度预置，另可保存 3 个自定义节奏。节拍器预设包含速度、拍号、分拍、重音和音色；鼓机预设包含速度、鼓组与各鼓件的静音状态。鼠标移到任一节奏上，点击右上角的 × 即可删除，预置和自定义节奏均可删除，重启后也不会恢复。在鼓机模式点击 60 / 90 / 120 速度预置，会保留所选鼓组。
- **界面：**浅色、深色、专注模式、窗口置顶。设置与自定义节奏保存在本机。

空格开始或暂停，↑ / ↓ 调整 1 BPM，Shift + ↑ / ↓ 调整 10 BPM，T 拍击定速，F 专注，M 静音，? 查看快捷键。输入框与弹窗保留标准键盘操作；按钮获得焦点后可用空格激活。

## 简易鼓机

选择左上角的「鼓机」，再选择右侧的节奏。六种节奏均为一小节循环的 4/4 拍：

| 节奏                 | 特点                                     |
| -------------------- | ---------------------------------------- |
| 基础摇滚 / Rock      | 八分踩镲，底鼓在 1、3 拍，军鼓在 2、4 拍 |
| 流行反拍 / Pop       | 切分底鼓，末拍开镲                       |
| 轻放克 / Funk        | 十六分踩镲、切分底鼓和轻军鼓             |
| 四拍迪斯科 / Disco   | 每拍底鼓，反拍开镲                       |
| 布鲁斯摇摆 / Shuffle | 三连音网格，长短 2:1 交替的踩镲          |
| 半拍律动 / Half-time | 军鼓落在第 3 拍，律动更舒展              |

所有鼓组的 BPM 都以四分音符为一拍，包括 Shuffle。调速不会改变所选鼓组，换鼓组不会重设速度。播放中切换鼓组或模式，在下一小节衔接。

节奏图显示底鼓、军鼓、踩镲三行，播放时标示当前步。点击左侧鼓名可分别静音或恢复；静音鼓件会画出虚线，名称加删除线。音量与静音也可统一控制整个鼓组。返回节拍器后，会恢复原来的拍号、分拍与音色。

鼓机同样支持渐进练习、定时结束、后台播放、深浅色及专注模式。旧版设置与已保存的节奏会自动兼容。

## 音频

发声与节拍时钟运行于 AudioWorklet 音频线程，保留非整数采样间隔的余数，不用页面定时器安排发声。底鼓、军鼓与踩镲在本地合成，不需要下载音频。闭镲会截断上一记开镲的尾音，暂停会清除所有鼓声尾音。界面根据音频输出时间同步指示；切换窗口或最小化后继续播放，渐进练习在小节边界更新速度。

## 开发与验证

```sh
npm ci
npm start
npm test
npm run pack
```

当前成品是 Apple Silicon 版本。开发工具及版本固定在项目根目录的 `package.json` 和 `package-lock.json` 中。

`npm test` 包含 16 项音频测试，覆盖时钟、原有音色、六种鼓组、Shuffle 摇摆、变速、小节衔接、鼓件静音、开闭镲、练习计时与异常输入。`scripts/qa.cjs` 检查原有节拍器交互，`scripts/drums-qa.cjs` 检查鼓机交互、实际音频输出和旧版数据兼容；运行 `npm ci` 会安装这些检查需要的 Playwright。测试使用独立的临时资料目录，不改动日常练习设置。

检查结果与自动生成的截图写入本机的 `qa/`，不提交到仓库。公开截图位于 `docs/images/`。`npm run preview` 可提供仅本机访问的浏览器预览，桌面版额外支持置顶与后台播放管理。
